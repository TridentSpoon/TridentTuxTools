# Project preferences

Use `tuxtools/assets/io.github.TridentSpoon.TuxTools.png` as the application
icon for future development, packaging, desktop launchers, and app branding.
It depicts Tux holding a trident in its own right flipper (viewer’s left)
and a wrench in its own left flipper (viewer’s right).

Preserve this approved icon. Do not replace or redesign it unless the user
explicitly requests a change.

The separately approved gaming-state variant is
`tuxtools/assets/io.github.TridentSpoon.TuxTools.Gaming.png`: Tux on a couch
with a controller, with the trident and spanner in front. Show it while an
active GameMode session is detected; retain the original icon for normal
branding and desktop launchers.
